# 文本型 PowerPoint 编辑

## 工作流

1. **查看原稿。** 记录页面尺寸、正文区域、区块顺序、现有字体和间距。确认条目由哪些段落、年份框和链接组成，区分同页列表与跨页续接。根据用户要求确定输出路径、是否修改源文件和是否导出 PDF。
2. **按条目编辑。** 从同一区块复用原生段落与文字格式。增删时把正文、日期或年份标签及链接作为同一个条目。只改超链接时，定位承载链接的文字范围并更新其目标。
3. **用实际行高重排。** 先在原正文宽度下测量换行。插入后顺延放不下的完整条目，删除后尝试从下一页回填，逐页核对后续承接。把标题、装饰线、正文和日期作为一个区块移动，按原稿各层级的间距对齐。
4. **验收结果。** 用交付环境的 PowerPoint 或目标渲染器重开并检查受影响的页面。核对条目完整性、样式、链接、页底和换页位置。需要 PDF 时从已确认的 PPTX 导出，检查每页渲染及实际链接目标。

## 工具选择

- Windows + 桌面 PowerPoint 可用时，优先用其原生排版测量行坐标、验收文件和导出 PDF。读取或试排可在临时副本进行，尤其是原文件已经打开时。
- 只调整少量坐标时，可定点修改 PPTX 的 Open XML。搬移段落时同步处理目标幻灯片的链接关系。若导入工具改变原稿换行或自动适应设置，使用能保留原排版的编辑路径，并以交付环境的渲染结果为准。
- 缺少目标渲染器时，优先做可确认的内容编辑和结构检查，并说明分页或导出仍需在哪个环境验证。
