# 文本布局与跨页重排

## 整理条目和区块

- 先按视觉顺序读取页面，把条目映射到段落、左栏标签和链接。记录区块名称和原顺序。对于多个正文框，确认哪些是上一页的续接，哪些是新节。用区块范围和条目顺序配对年份，遇到计数不符时定位缺项后再移动。
- 插入时复制同类条目的段落格式，复用作者加粗、题名斜体、会议信息和链接格式。替换相应文字范围并设置新链接地址。删除时移除整条正文的段落及其分隔符、年份框和对应链接。每次增删后检查相邻条目之间的间距。
- 保留原稿已有的原生文本、换行设置、字体和页面尺寸。将正文、年份和链接作为不可拆分的条目移动。标题、装饰线、左右栏和其他对齐的形状作为一个区块定位。

## 计算页面容量

1. 在原有正文宽度和样式下排版试改条目，读取第一行和最后一行的行框。实测行高包括字体与换行带来的差异。用行框底部核对页面可用空间，顺带检查形状边界或裁切设置是否会遮住文字。
2. 根据原稿页边距、页脚和安全留白确定文字可用底边。计算整条高度和与前一条之间的标准间隔。比如可用高度为 120 pt，三条的文字高度为 42、39、35 pt，标准段间距为 6 pt，三条总高为 128 pt，因此第三条应放在下一页。
3. 从发生变化的页面向后重排。插入时依序把超出容量的完整条目推到下一页。删除时用下一页的首条尝试回填，逐条试到再放一条会超过底边为止。每次跨页移动后继续检查后一页，直到接续位置稳定。
4. 给新节标题和至少一条正文预留同页空间。章节移位后，从同页前一区块的实际文字底边重新定位后续区块。末页的留白可以来自正常的剩余内容。若用户要求固定页数且完整内容放不下，先判断能否沿用模板允许的间距或版式，再就实质取舍确认。

## 对齐与间距

| 对象 | 测量与调整 |
| --- | --- |
| 论文或履历条目 | 从同类条目读取段前距、段后距和行距。验证过程中区分段落内部换行和相邻条目之间的间隔，防止重复计算段后距。 |
| 年份和日期 | 左栏保持既有的统一横向对齐方式。将年份文字与对应段落实际第一行对齐，题名前有作者时以作者所在的首行为基准。 |
| 奖项列表 | 奖项采用自己的行距和段间距，左右两栏逐条配对。遇到多行奖项时核对下一条左栏标签有没有跟着右栏真实行高移动。 |
| 相邻区块 | 以前一区块最后一行行框的底部到下一标题行框的顶部为基准。双栏取较低的真实文本底部。统一同级标题的间隔，按相同位移移动标题、蓝线等装饰和对应正文。 |

验收时逐页核对条目顺序和数量、日期归属、间隔、最后一行完整性，以及后续区块有没有因为插入或删除而产生大空档、重叠或溢出。定点对齐可在相同渲染环境和尺寸下比较前后截图，定位目标区之外的意外差异。
