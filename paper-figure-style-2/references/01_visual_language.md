# 视觉语言与版式

## 风格边界

- **系统图**：浅色大分区、低对比背景、深色分区标题、白色或近白小卡片、鲜明图标、细直线箭头。图标使用独立的主色与点缀色，避免整区变成同一种灰绿或灰紫。
- **实验图**：白底、细灰轴线、轻虚线网格、紧凑图例和稳定色序；突出任务分层与面板对齐。
- **与风格 1 的区别**：本风格采用纯色分区和白底统计画布。桃紫连续渐变背景属于 `paper-figure-style-1`，不自动加入本风格。
- **默认字体**：使用 Matplotlib 自带的 DejaVu Sans，避免依赖系统 Arial。主标题和分区标题加粗，轴标签与说明用常规字重。

**统计色序**：分类填充保持柔和，和系统图的鲜明图标分开控制。

- **六类柱色**：`#A1B8DC`、`#A9DDBB`、`#F6C99B`、`#D0C6E7`、`#FBE8C7`、`#A7DBE2`。
- **Harness 三色**：深蓝 `#3070B5`、浅蓝 `#77BCEB`、薄荷 `#6CD6B4`；第三组可用 `#83CADF` 与深青 `#239C88`。
- **双模型曲线**：蓝 `#0072BD` 与青绿 `#29CFA9`。
- **明细分数**：达到阈值使用浅青 `#B6ECFD`，低于阈值使用灰 `#D4D4D4`。
- **热力图**：从近白 `#F7FAFC` 经浅青到深蓝 `#3070B5`；缺失单元用中性灰底和短横线。
- **失败组成**：浅蓝、杏橙、薄荷、淡紫、淡黄等分类色；同一失败类型跨面板保持同色，即使扇区顺序不同。

## 尺寸与文字

- **系统图逻辑宽度**：1100 单位；默认物理宽度 11 英寸。`Diagram` 的字号、线宽和图标尺寸均使用逻辑单位。
- **系统图建议字号**：分区标题 20；卡片标题 12–17；说明 9–14；缩略表格 6.5–9。长标签先改为短名称或换行，再使用 `max_width` 小幅缩放。
- **统计图建议字号**：主标题 10–11 pt，轴标签 8–9 pt；54 面板矩阵内部为 5.9–7.7 pt。统计示例导出时按 `width_in` 等比缩放字体与几何。
- **线宽**：轴线约 0.5 pt，网格约 0.5 pt，统计曲线约 1.05 pt，误差线约 0.45–0.7 pt。
- **最终验收**：默认较宽画布便于查看细节；将 54 面板图放入单栏会使文字过小，优先整页展示或拆成三个评测集。

## 参考覆盖与适配说明

风格依据为用户提供的 *Agents-Eval: A Lifecycle Platform for End-to-End Agent Evaluation*。代码示例分别覆盖原文图 1–9 的结构：组件总览、生命周期、覆盖与径向画像、响应曲线、Harness 矩阵、重复运行、失败组成、界面说明、任务证据表。只借鉴视觉组织，不需要参考 PDF 作为运行输入。

- **保留**：图的层级、色系、分组方式、面板密度、轴线和注释样式；分区、生命周期和主要统计色值对照 PDF 矢量对象读取，图标主色参考原图局部色彩。
- **示例内容**：换用虚构的评测集、模型和任务；统计量从公开可读的演示代码计算。图中数值不是对论文实验结果的重现。
- **图标与界面**：使用自绘矢量图标与界面示意，替代论文中的品牌素材、照片和真实软件截图；这些部分保留版式，不声称是原应用的实际截图。
- **字体差异**：DejaVu Sans 替代原图 Arial，保证跨机器可运行。若项目已具备合法可用的 Arial 或兼容字体，可通过 `theme(font=...)` 指定并重新验收。
- **统计表达调整**：柱图保持零基线；观测区间外用虚线标外推；拟合使用显式 L2 正则的二项似然，不添加伪观测锚点。这些选择保留风格，同时使示例的数据含义独立可解释。
