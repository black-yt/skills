# 视觉语言与参数

## 配色

| 角色 | 色值 | 使用方法 |
| --- | --- | --- |
| 主文字 | `#16151C` | 标题、节点名称、关键判断 |
| 次文字 | `#5C5C66` | 输入说明、补充条件、资源与产物 |
| 方法紫 | `#584B9A` | 计算模块、方法流向、学习、工具与规则 |
| 领域赭 | `#A4592F` | 领域输入、专家知识、验证条件 |
| 资料蓝 | `#4C6D91` | 文件、数据、知识源 |
| 确认绿 | `#537D58` | 验证通过、可信结果 |
| 中性边框 | `#CBCBD2` | 白卡片轮廓、分隔线、次级连接 |
| 浅桃背景 | `#FBF3EE` | 渐变左端、领域与验证卡片底色 |
| 中间背景 | `#F6F2F5` | 渐变中间色 |
| 淡紫背景 | `#F3F2FC` | 渐变右端、计算与方法卡片底色 |
| 白色 | `#FFFFFF` | 主要内容卡片 |

- **渐变范围**：通常覆盖整张画布，颜色停靠点为 `0 / 0.5 / 1`；区域分组再叠加透明度约 `0.5` 的浅色块。
- **实现方式**：`Figure.gradient()` 使用原生 Type 2 轴向 PDF shading，经圆角路径裁切；PDF 放大时不受像素分辨率限制。
- **语义优先**：颜色分工可适配用户的内容，图内必须一致；不要为了凑齐颜色给无差别的对象赋予不同含义。
- **强调节制**：大面积背景保持浅色。流程图的强调色用于边框、图标和箭头；统计图允许实心柱、曲线与点使用分类色，背景仍低对比。

## 统计图配色与细节

- **分类色**：`charts.COLORS` 提供赭棕 `#A36840`、松绿 `#3E846B`、柔紫 `#7261D3`、蓝 `#4874C5`、青 `#3E8495`、金棕 `#927333`、莓红 `#BE5378`。按方法家族分配，跨图保持一致。
- **区间带**：沿曲线同色绘制，透明度约 `0.11–0.15`；中心线宽约 `1.35`，不要让阴影遮住线型。
- **透明度实现**：ReportLab 的颜色设置可能重置 alpha。必须先设置填充/描边颜色，再设置透明度；`check_charts.py` 会检查实际渲染灰度，避免只检查参数却漏掉不透明输出。
- **坐标轴**：只保留左、下细轴线，水平网格约 `0.45`；柱状图从零开始，散点图可用明确标注的对数轴。
- **统计字号**：常规轴标与短标签为 9–10.5；密集训练面板的刻度为 8。五列仪表盘应按双栏宽度使用，若需更大字号应增大物理宽度或拆成多页。
- **分组**：小多图采用统一圆角面板、对齐标题与图例；同类面板共享数值范围，不同单位的矩阵列保留各自刻度。
- **环形图**：使用粉彩扇区、白色间隔与简短编号；编号解释移到图例，中心保留总数。层级环的内外边界必须由同一份子项计数计算。
- **模型 logo**：放在柱底与模型名之间，通常 16–20 逻辑单位；使用内置原始 PNG，名称仍为独立文本，调用方式见 [模型 logo](05_model_logos.md)。

## 尺寸与字体

代码使用左上角原点、向下为正的逻辑坐标。默认宽度是 720，输出宽度是 7.2 英寸，因此 1 个逻辑单位对应 `0.72 pt`。

| 元素 | 逻辑参数 | 默认 PDF 中的大小 |
| --- | --- | --- |
| 主标题 | 15，DejaVu Sans Bold | 10.8 pt |
| 分区标题、节点标题 | 12，正常字重 | 8.64 pt |
| 正文、说明 | 11 | 7.92 pt |
| 短注释 | 10 | 7.2 pt |
| 常规卡片描边 | 0.8 | 0.576 pt |
| 分隔线 | 0.65–0.85 | 0.468–0.612 pt |
| 主连接线 | 0.9–1.05 | 0.648–0.756 pt |
| 卡片圆角 | 6，较大卡片可用 7 | 4.32–5.04 pt |
| 小图标 | 13–19 | 9.36–13.68 pt |

- **物理大小**：缩成半栏会同比缩小文字和线宽；需要单栏图时应减少节点或改成纵向布局，不能只把横向五卡片图压缩到很窄。
- **字体一致**：默认从 Matplotlib 安装资源定位 DejaVu Sans Regular/Bold，由 ReportLab 嵌入 PDF，不依赖某台机器的绝对字体路径。
- **中文标签**：通过 `--font-regular` 和 `--font-bold` 提供支持中文的 TrueType 字体；当前默认字体不覆盖中文。复杂数学排版也需要额外的布局实现，不能把 LaTeX 源字符串直接当作公式交付。
- **字重节制**：主标题用 Bold，主体正常字重；不要把所有卡片标题都加粗。

## 布局

- **先选拓扑**：串行阶段用并排等宽卡片；一个输入影响多个模块时用折线分支；共有输出送给多个用途时用水平总线。
- **边距**：主内容通常从 `x=14–16` 开始，右侧保留相近边距；不要让文字贴住边框。
- **对齐**：分区标题与该区首张卡片对齐；同层卡片统一顶边、高度和标题基线。
- **留白**：卡片内标题、图标、说明、产物条形成明确分区；增大空白通常优于增加装饰。
- **连接线**：端点停在卡片外约 2–4 个单位；箭头沿阅读方向走，不穿过文字。跨区连接优先沿留白走折线。
- **状态矩阵**：用行表示对象、列表示判据，符号旁边写 `Runs / Passes / Fails / Ungraded` 等文字，确保含义不只依赖颜色。
- **图标**：使用统一线宽的几何线稿；复杂大图标可由文件、立方体、核对标记等小组件叠加。

## 示例设计

- 每个示例对应一个新用户能直接提出的完整需求。
- 场景、节点、标签都在示例代码内，不需要外部 PDF 或图片素材。
- 保留核心风格参数，允许根据新内容调整节点数量、宽高、图标和连接方式。
- 方法示例展示系统关系；统计示例包含明确标注的虚构数值与演示区间，不能声称为测量结果。

## 风格来源

这套视觉语言参考了 [ScienceIDE 的方法与统计图](https://arxiv.org/abs/2609.19134)。示例采用独立研究场景、文案与演示数据，通过可复用代码绘制；使用者无需阅读论文或下载参考素材。
