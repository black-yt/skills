# 独立模拟审稿与多轮修订

适用：用户要求用多个独立审稿 agent 改进论文，且当前环境允许委派。目标是发现并修复可证实的问题；积极录用态度是审稿结论，不是评审提示的约束。没有此类需求时，不把本流程强加给普通写作或语言润色。

## 启动与冻结

- **核规则。** 查当届、对应阶段的官方要求；作者指南、审稿量表和模板不是同一资源。审稿指南不存在时明确记录，不冒用往届分数。
- **同版本。** 每轮给所有审稿人相同的主 PDF、补充及必要源码，记录提交号与 SHA256。评审期间只改工作副本，不能让审稿人读到被作者悄悄替换的版本。
- **分视角。** 例如三位分别侧重任务/视觉价值、数据与实验有效性、论证/新颖性；这不是限制其他问题的检查权，也不是三次调用就获得三个人类专家的独立性。
- **隔离判断。** 初审使用新上下文；不继承用户期望的录用目标、作者的抗辩、其他审稿人的分数。每个 agent 只写自己的评审文件，不能直接改论文、运行付费实验、提交或推送。
- **披露不可避免的上下文。** 新上下文不保证完全盲审：仓库必读指南可能含旧评审摘要。遵守适用指南并记录实际暴露范围，不把它称为完全未接触历史的外审；更换上下文也不能伪称原审稿人改票。
- **控制长度。** 要求少量有决定作用的主要问题，附页码、原句、案例或计算；避免每轮复制完整旧评审，复审重点报告改变了什么。
- **先读论文。** 以主稿和补充为常规审稿入口，先判断资源或方法的新意、证据与写作是否形成完整论证。源码、原始题目和逐项日志用于回答具体疑点，不作为所有论文必须通过的全量取证前置条件；需要专门审计时单列其范围与结论。
- **匹配投稿阶段。** 区分初审材料要求、接收后的公开承诺和camera-ready可用时间，以当届官方规则为准。初审不要求全库或全部代码公开时，不将缺少公开平台访问本身当作拒稿理由；仍评价稿内质量控制、实验和来源说明是否足以支撑贡献。作者补充的真实专家流程可作为方法事实写入，缺少本地历史答卷不自动等于没有审核；不编造抽样方式、逐层比例、精确计数或一致性指标。
- **按影响衡量缺陷。** 数据论文无需声称逐题完美。区分个别噪声、系统性偏差和核心结论失效；定向发现不能外推总体发生率。训练若仅是使用验证，不按新训练方法要求原创算法，但其报告数值仍须诚实。正文先说清资源价值与发现，局限集中说明，避免重复免责声明淹没贡献。

可直接使用的初审提示：

```text
独立审阅 [冻结版本]，按 [当届官方规则] 判断贡献、有效性和可复现性。
你的侧重点是 [视角]，但可指出任何影响结论的问题。
仅阅读指定材料，不看其他审稿意见或作者内部结论；不修改论文。
报告优点、按严重度排序的主要问题、证据位置、作者问题，
并区分写作可修复与必须新证据的问题。
独立给出支持/边缘/拒绝及置信度，说明改变判断的最低证据。
没有预设评分；未知根因保留为未知，不断言未经证实的实现错误。
将意见写到 [专属文件]，末尾记录所读文件哈希。
```

## 问题到证据的分流

| 类型 | 作者应做什么 | 不能用什么替代 |
| --- | --- | --- |
| 读者误解了定义 | 指向原文并检查定义是否可见、术语是否统一 | 要求审稿人降低标准 |
| 实际输入或设置披露不全 | 查逐字请求、运行配置和版本，再准确补写 | 把代码默认值写成实际设置 |
| 可读案例与分数冲突 | 对照原始响应、提取状态、评分器和记录版本，离线重放 | 直接用摘要手算分数覆盖正式结果 |
| 精确标签可能欠定 | 核对决定性信息是否在模型输入中；需要时做盲于金标的独立审计 | 隐藏原协议、gold reasoning 或更多检查项名称 |
| 模态、组件或泛化贡献不明 | 整理已有受控对照，或提出范围匹配的最小实验 | 引用别人的多视角方法来证明自己的视觉贡献 |
| 来源复用或划分边界不明 | 分别统计实例、协议、源窗口、跨任务和视图路径关系 | 以金标字符串不同推导没有来源暴露 |
| 需要新实验/标注 | 在授权范围内补证据；缺记录则保持待核 | 猜数值、猜平均方式、伪造人审覆盖率 |
| 版式与匿名风险 | 独立走编译、守恒与视觉验收 | 用“审稿人支持”替代模板检查 |

冻结证据中的脚本应能定位其依赖和固定版本输入；按原仓库相对路径写的脚本，复制到冻结目录后可能无法运行。只提供汇总 JSON 和脚本而未提供原始输入与评估器时，审稿人只能核逻辑和统计，不能称为独立端到端复算。可提供自包含材料，或明确授权只读访问同一固定版本依赖并记录其哈希。

回放缓存的已解析程序只验证“解析结果到分数”，对缓存 null 直接归零也未重验提取是否正确。必须另列原始响应提取、评分重算、金标有效性和 trained/agent 轨迹的覆盖；不能将其中一项通过写成整条链路已验证。

原始输出可能因位置参数、包装、未定义引用或抽取失败整体计零，而人工整理的动作名摘要看起来有部分匹配。应分别呈现原始序列化、解析结果、语义摘要和得分，说明哪一个被评价。离线重放已有输出通常比重新调用所有模型更适合先定位这类矛盾。

补查原始证据时，还应区分：

- **失败类别。** 有原始文本却提取失败、网络/服务请求失败、响应缺失不是同一种能力错误。按同一gold版本分别报告raw覆盖、成功程序一致、失败状态一致、缺失和排除项；归零约定可复现不代表这些零分都来自模型推理失败。
- **训练链路。** 本地忽略文件缺失时，可检查已知公开模型资源的固定revision及小型日志，避免把“当前checkout没有”说成“记录不存在”。配置上限、trainer实际步数、最佳loss检查点、实际发表预测检查点和对应数据版本逐层核对；仅找回state/loss仍不能宣布任务成绩复算成功。
- **案例版本。** 同名ID或图像文件名可能来自旧版本。对齐实际question、options、图像和gold后才称为当前测试实例；未找回映射则保留版本缺口，不据此指控伪造或强行替换原案例。
- **目标覆盖。** 除了“精确参数能否由输入决定”，还要核对gold是否表达明示目标，不能临时为动作加未公开的宏语义来解释遗漏。定向文本/接口诊断不等于专家人审、总体错误率或有效替代计划认证；发现反例要与评分重放分别记录。

固定样本数的精确准确率有离散步长。例如单次200题准确率只能以0.50个百分点变化。结果不符合时，先确认是否多次平均、样本集不同或指标不同；不能擅自取整或编造平均过程。净增若干个正确题也不等于配对显著性；仍需错转对、对转错及相应统计。

## 修订、复审与停止

作者维护一张表，而不是仅收集好听的改写：

| 问题ID | 证据/版本 | 本轮修改或复算 | 仍缺什么 | 复审结论 |
| --- | --- | --- | --- | --- |
| [ID] | [页/样本/哈希] | [具体动作] | [缺口或无] | [解决/部分/未解决] |

- **先实质后语言。** 先核标签、评分、来源和比较，再润色；限定贡献不等于修复无效标签。不要将所有问题都降格成 future work。
- **保留数据。** 新证据与原结果分开，标注核验范围。若仅重放了一部分同版本直接输出，不能说所有模型、训练和 agent 成绩均已验证；不同金标版本的记录应列为排除项。
- **将证据缺口交给对应来源。** 抽样人审、发表检查点映射和第三方分发权限分别需要真实审核、运行记录和来源材料；更多模型请求通常不能补齐。可先准备固定抽样及盲于参考的题面包，锁定第一阶段答卷后再开放参考/来源做覆盖与歧义裁决。准备好材料不等于审核已实施，模型自查不写成人审；分层抽样的全库估计要匹配总体权重与相关性。
- **局部改稿。** 在授权范围内修改，保留原实验数字和证据。会议稿每次语义修改后都要回到页数、引用、图表和视觉检查；短尾优化不能引入新结论或删除重要限定。
- **独立复审。** 将新冻结稿和可复核的变更/证据交给各原审稿人，允许撤回旧批评，也允许维持拒绝。不给其他人的评分，不提示“还差你一个接受”。
- **实质停止。** 三人确实支持时，记录依据后结束；若反复指向同一缺数据/实验问题且没有新证据，结束这种重复采样，交付真实状态和最小下一步。不能为了满足“直到录取”的指令制造支持态度，也不能把未达到的目标写成完成。
- **分开验收。** 科学意见、模板技术验收、作者资料/许可、系统提交分别记录。更新可见的LLM使用声明及保密问卷对应项；不暗示做过真实投稿或官方评审。

## 获准后的有限补实验

- **先选决定性对照。** 用少量模型和固定随机/哈希子样本补具体缺口；在调用前冻结题目、模型别名、提示、视图、图像哈希、评分器、主次比较及首次请求上限。不按效果挑模型、替换题目或追加到显著；运行中的设计修订单独标注，不能追溯称为预注册。
- **分开图像作用。** 无图、固定单图、全部原图和错配图各回答不同问题。错配若同时改变相机标签/组合，只解释为整套视觉输入干预；有图优于错图不自动表示有图优于无图。固定首图不代表最佳单图。
- **交换后换真值。** 新建相同文本、不同图片且已知类别相反的配对诊断时，交换图片后按新类别计分；同时报告正确切换、两成员均正确和重复输入的一致性。它只验证新增任务，不能用识别成功覆盖原动作题的欠定标签或负结果。
- **图名不是图审。** 资产类别、容量或孔板规格可能与实际几何不一致。查看所有选中视图，必要时实际计数；能确认外形时不用它认证不可见功能。调用前排除/合并类别也要保存候选和理由，不把通用模型看图写成人类领域认证。
- **正确统计单位。** 给出原计划分母、逐题配对差、错转对/对转错和区间；多比较明确校正。共享资产、相同文本或成对反事实应按相应组做敏感性分析，不能将请求数当独立样本数。全成功的小样本 bootstrap 可退化为零宽区间，不据此宣称总体无误。
- **分开来源与视觉信息。** 当来源索引可用而实际题面可能缺少协议条件时，可按固定子样本设计来源上下文×图像的交叉控制。源步骤按原索引机械选取并预先冻结，四格同轮新测；来源可能直接给出目标动作或常数，故称source-oracle输入变体，不当作检索、原题修复或标签有效性认证。主比较按题聚合，少量相关请求不能充作独立样本；来源点估计提高但区间跨零时，不转写成已确立增益，也不只挑有利子格。
- **核实际预算。** 网关别名与返回名不能认证上游身份；requested token cap、temperature 与实际执行也须区分。先做少量兼容性检查，保存 usage；没有报价不猜货币花费，不因请求了上限就宣称统一推理预算。
- **区分截断与空输出。** finish reason为length且文本中没有最终答案，与空响应和请求失败分开统计。若因此追加预算跟进，使用同一完整样本、相同提示和单一配置改动，注册新版本后再调用；不能只挑之前失败项或回溯称首轮预注册。取消max_tokens只表示请求未指定上限，服务实际默认预算仍未知。
- **防重复付费。** 发请求前持久化尝试身份和版本；归档加排他锁，读取缓存及统计时核 manifest、ID、模型、条件和原始文件哈希。保护检查不能因优化运行模式失效。进程中断时区分已保存响应、确定未发出和可能已发出但未保存；后者不静默重抽。没有原始字节的失败保留为覆盖缺口，不称完整端到端复现。
- **保留版本边界。** 新题、新指标和新模型调用保留原始版本，不用新分数覆盖旧榜单。不能由缺失信息倒推希望的常量来修题；若缩小目标，明确是新局部任务。需要领域裁决的问题不由自动修复或更多 API 调用代替。
- **记录评审执行失败。** 评审进程被平台中止不算支持或拒绝。确需恢复时记录原因、上下文和审阅范围；不得换人只为得到正评，限定范围的统计复核也不能冒充完整第三份论文评审。

## 可复用交付

保留各轮原始评审、冻结文件清单/哈希、作者处置表、脚本和核验输出摘要。构建与预览按项目约定留在忽略目录。总结到通用技能时保留方法与失败处理，去除一次性项目路径、身份、凭据与未经核验的成功故事。


### 可见功能子集与新诊断

原题可能通过文字提供操作类别，却用精确参数区分选项。按资产类别分组不保证原gold由图像决定；可先在不读模型得分的条件下检查可见线索，另建有限的功能诊断。固定纳入/排除规则、原首视图与任务定义，再调用模型；不得事后换题追显著性。新功能匹配结果与原下一步任务分开报告。

重复几何、动作类别不平衡和完全相同的无图prompt会降低有效独立信息。小样本除题级分数外，报告相应分组敏感性与类别宏平均，区分均匀随机和多数类别基线；请求数量不是独立任务数量。允许OCR时明确视觉效果包括面板文字，不外推为纯几何推理。


### 评分接口故障的离线修复

调用前用模型实际提示允许的输出形式核对解析器，例如“只答字母”必须能被提取。若完成请求后发现解析器错误拒绝遵从提示的响应，不重发付费调用、不改原冻结执行器：保存旧评分，另行冻结兼容规则与离线评分版本，对全部计划位置统一复算并独立核查。只接受完整明确答案，不从解释正文猜选项，不参照gold逐题调规则；接口故障的全零结果不能当模型能力结论。


若评审工具技术失败且未产生意见，可有限恢复或启用明确标识的技术替代身份。保留失败次数、替代关系、相同冻结材料及实际阅读范围；不把替代结论写成原评审改票，也不以技术恢复为名更换已经有效给出负评的身份。
